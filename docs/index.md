# Records what was proposed, run and produced.

Event-sourced bounded contexts over Postgres, hexagonal ports and adapters, and
equivalent REST and agent-protocol surfaces backed by a single handler per command.

Every operation is published twice, as an HTTP route and as an agent-facing tool, from
one handler, so the two surfaces cannot drift apart.
